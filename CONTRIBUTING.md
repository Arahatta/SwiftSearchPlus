Thanks for considering a contribution.

1. Open an issue before making a large or behavior-changing proposal.
2. Keep changes focused and explain the Windows version and filesystem used for testing.
3. Build on Windows with Go 1.23+ and Python 3 by running `build.cmd`.
4. Include reproduction steps for UI hangs, search mismatches, cache issues, or DPI problems.
5. Do not submit copyrighted upstream assets unless you have permission to redistribute them.

This project is experimental. Please identify which features you tested on a real Windows machine.
